Say what should exist; the controller makes it so.

Cloudplane holds a store of cloud resources, a desired state and a schema for every kind it knows. Plan diffs the store against the desired state and returns create, update and delete actions. Reconcile applies them, writes the desired spec of the resource and reports the ones that could not be written. The generation goes up every time the desired state changes.

Architecture

How it works

control.go holds the model and the controller. Resource carries an api version, a kind, a name, a spec, a status, a resource version, the conditions and the observed generation. Store keeps the resources in a map under the key kind/name, with a counter that gives every write a new resource version; Update only writes when the version of the caller is still the one in the store, so a concurrent write is refused. SchemaRegistry holds a Schema per kind with the required fields and the allowed values, and Validate refuses a resource without a name, without a required field or with a value that is not allowed; a kind without a schema is accepted. Plan diffs the current and the desired resources into create, update and delete actions and sorts them. ReconcileWithSchemas applies the plan and collects the failures. Controller keeps the desired state, SetDesired validates it and raises the generation, and Reconcile plans and applies in one step. Server serves /api/resources, /api/desired, /api/plan, /api/reconcile and /healthz, and FileStore keeps the resources in a JSON file. main.go registers the schemas of the Bucket and the Database and runs the demo with -demo or the API with -serve.

The API

Endpoints

MethodPathWhat it does
GET/api/summaryThe counters: resources, desired state, generation, plan and schemas
GET/api/resourcesThe resources of the store with their status and their condition
GET/api/planThe actions that bring the store in line with the desired state
GET/api/schemasThe schemas of the kinds the control plane knows
POST/api/desiredSet the desired state and answer with the new generation
POST/api/reconcileApply the plan to the store and answer with the applied actions

GET/assets/theme.cssThe design system of this site
