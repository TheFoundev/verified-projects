Commit the ciphertext, never the password.

secretsync keeps the secrets of every environment encrypted inside a Git repository: each environment has its own age recipients, decryption is only allowed inside CI, key rotation keeps the old recipients readable for a while, and every operation lands in a hash-chained audit trail.

What it does

The capabilities

Every panel below is served by the real API of this project — nothing here is a mock-up.

◆

One key set per environment

Each environment is encrypted to its own age recipients, so a staging key never opens production.

⛨

Decryption only in CI

The decrypt is refused on a laptop and only proceeds when the CI variable and the run marker are there.

⟳

Rotation with a grace period

The old recipients keep reading until the grace period ends, and the reminder days are tracked per environment.

⛓

A trail that cannot be edited quietly

Every record hashes the previous one, so a rewritten or truncated trail is detected.

✔

A gate in front of every commit

The pre-commit hook rejects plaintext secrets, unencrypted files and a broken chain.

⊘

Plaintext never lands in a commit

Encryption is refused while another tracked file still carries a secret in cleartext.

Architecture

How it works

The configuration file .sops.yaml maps every environment to its own age recipients, its own creation rules and its own rotation reminder. Encrypting re-keys a file to the recipients of its environment through sops, while decrypting is only allowed when the policy sees the CI variable and the run marker. Every operation is appended to a JSONL trail in which each record hashes the previous one, and a side-car checkpoint catches a truncated tail. The pre-commit gate runs the same checks over the working tree before anything is committed.

The API

Endpoints

MethodPathWhat it does
GET/api/summaryThe environments, the encrypted files, the records of the trail and the state of the chain
GET/api/auditEvery record of the hash-chained audit trail
GET/api/environmentsThe recipients, the grace recipients and the rotation date of every environment

Quick start

Run it locally

# bash scripts/fetch_tools.sh                 # the sops and age binaries into .tools/
# python3 -m secretsync init --envs dev,staging,prod
# python3 -m secretsync check                 # the pre-commit gate
# python3 -m secretsync audit verify --check-files
# python3 web/server.py --port 8200           # this site
# pytest -q                                   # 96 tests
