An append-only log per topic, with consumers that acknowledge.

Eventwire keeps its topics in memory. Publishing appends a message with an offset, a key and a timestamp to the topic and trims the topic when it grows past the retention. A consumer polls the topic from its own offset, the polled messages stay pending until they are acknowledged, and the messages of one key always land in the same partition.

What it does

The capabilities

Every panel below is served by the real API of this project — nothing here is a mock-up.

⌗

Append-only topics

Publish appends a message with an offset, a key and a timestamp to the topic of the broker.

◑

Offsets

Every topic has its own counter, and Fetch returns the messages at or after an offset.

⇄

Four partitions

partitionOf hashes the key, so the messages of one key always land in the same partition.

⏱

Retention

When a topic grows past the retention, the oldest messages are trimmed away.

✓

Acknowledgements

Poll marks the messages pending, Ack clears one offset and Pending counts the ones that are left.

▤

An HTTP API

PublishHandler and FetchHandler take the topic, the key, the payload, the offset and the limit from the query.

Architecture

How it works

queue.go holds the broker. Message carries a topic, an offset, a key, a payload and a timestamp; Topic keeps the messages and the offset of the next one behind a sync.RWMutex. Broker holds the topics in a map and the retention. NewBroker takes the retention, broker.topic finds a topic or makes one. Publish appends the message, gives it the offset of the topic and trims the front of the topic when it is longer than the retention. Fetch returns the messages at or after an offset and stops at the limit. partitionOf hashes the bytes of a key into the four partitions of the constant Partitions, so the messages of a key keep their order, and PartitionOf and PartitionsOf expose that to the caller. Consumer holds an offset and the pending offsets: Poll fetches the messages from the offset, marks them pending and moves the offset, Ack drops one pending offset and Pending counts the ones that are left. PublishHandler and FetchHandler read the query parameters topic, key, payload, offset and limit. main.go makes a broker with a retention of 100 and publishes two messages to the topic orders.
