What the plan will cost before it is applied.

Costwatch reads a Terraform plan document, takes the resources of the root module and of the child modules and prices every one of them from a small table of AWS and Google prices. It returns the total, the total per resource type, the total per provider and the resources it could not price, because a resource with no price may still cost money.

What it does

The capabilities

Every panel below is served by the real API of this project — nothing here is a mock-up.

▦

Plan parsing

ParsePlan reads planned_values.root_module and the resources of the child modules.

⚖

Price table

A small table of AWS and Google prices; a resource with no price is named, not counted as free.

◑

Totals

EstimateAll returns the total, the total per type and the total per provider.

◈

Provider split

The provider is taken from the type of the resource, the way Terraform writes it.

▤

JSON API

Handler serves the summary of the plan as JSON over HTTP.

⌬

Modules

The resources of a module are part of the plan, not a second plan.

Architecture

How it works

cost.go holds the model and the prices. ParsePlan reads the resources of planned_values.root_module in the plan JSON and appends the resources of the child modules. EstimateResource prices one resource from its type and its values: instancePrices for aws_instance, databasePrices for aws_db_instance, googleComputePrices for google_compute_instance, a rate per GB for aws_s3_bucket and aws_ebs_volume, and a fixed price for a Google SQL instance. EstimateAll adds the estimates into a Summary with the total, ByType, ByProvider and the names of the Unpriced resources. main.go holds the example plan and the command line, api.go serves the summary as JSON with Handler.
