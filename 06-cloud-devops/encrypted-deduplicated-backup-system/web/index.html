A backup that keeps every piece of a file once.

Vaultbox cuts a file into chunks with a rolling hash, skips the chunks that are already in the repository and encrypts every new chunk with AES-GCM. The manifest lists the chunks of every file, so a restore reads the chunks back, opens them and writes them together. The key comes from PBKDF2 over a secret and a salt, so the same secret gives a different key on every machine.

What it does

The capabilities

Every panel below is served by the real API of this project — nothing here is a mock-up.

⌗

Rolling chunking

ContentDefined cuts the file on the boundaries of a rolling hash over the last 64 bytes.

⇄

Deduplication

A chunk that is already in the repository is not written again; Put counts the new chunks only.

⛨

AES-GCM

Every chunk is sealed with its own nonce, and the nonce is stored in front of the ciphertext.

⚙

PBKDF2

The key is derived with PBKDF2 over HMAC-SHA256, 120000 rounds, with a salt of 16 bytes.

▤

Manifest

The manifest maps every file name to the list of its chunks, and it is written next to them.

↻

Restore

Restore reads the chunks of the manifest, opens every one of them and writes the bytes together.

Architecture

How it works

repository.go holds the repository. ContentDefined cuts the data on the boundaries of a rolling polynomial hash over the last 64 bytes, with the bounds 32, 96 and 192, so a byte that is inserted at the front only moves the boundaries near the front. chunkID is the SHA-256 of the chunk, in hexadecimal. seal and openSealed use crypto/aes with cipher.NewGCM, and the nonce is written in front of the ciphertext. deriveKey calls pbkdf2Key, which is PBKDF2 with HMAC-SHA256, 120000 rounds and a key of 32 bytes. Repository holds the directory, the key, the salt and the manifest; Put writes every new chunk as a file with the id of the chunk and the suffix .enc and counts the new ones, Restore reads the chunks of the manifest and writes them together, and Save writes manifest.json. main.go backs up one file with -source or restores one with -restore.
