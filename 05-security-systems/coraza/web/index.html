Look at the request before the handler sees it.

Bulwark matches the path, the query and the body of a request against four regular expressions: SQL injection, cross-site scripting, path traversal and scanner signatures. Every match becomes a finding with a severity and the text that matched it, the findings are scored and a score of two or more blocks the request. The escapes are decoded once before the request is read, so an address written as %3Cscript%3E is caught as well.

Architecture

How it works

waf.go holds the engine. The rules slice holds four Rule values with an id, a category, a severity and a compiled regexp. Inspect runs every rule against the path, the query and the body and stops at the first field that matches, so a request gives at most one finding per rule. Score adds the severities up and Blocked reports a score of two or more. Inspectable turns an http.Request into the Request the firewall reads and decodes the escapes once with url.PathUnescape, and Middleware puts the same decision in front of a handler. main.go is the command line that inspects one request and prints the decision, the score and the findings as JSON.
