Ask every port of a host and keep the answers that came back.

Knock reads a port list like 22,80,8000-8010, dials every port of a host at the same time and writes the state of each one. A port that accepts the connection is open and a port that refuses it is closed. The host list also understands a network written as 10.0.0.0/30, which is expanded into its addresses. The results are written as JSON, with the open ports of the host.

Architecture

How it works

scanner.go holds the scanner. ParsePorts reads the list, expands the ranges, drops the ports that are out of range and sorts what is left; ParseHosts reads a list of hosts and networks, and expandNetwork turns a network into its addresses with nextAddress as the address behind the last one. Scan dials every port of a host at the same time with net.DialTimeout and writes a PortResult with the state open or closed; OpenPorts filters the open ones and sorts them. DefaultTimeout is 400 milliseconds. main.go reads the host, the ports and the timeout from the command line and writes the results and the open ports as JSON.
