Every block accounted for.

A thread-safe malloc and free replacement built on a single mmap arena: 16-byte alignment, first-fit allocation, block splitting and a coalescing free list.

What it does

The capabilities

Every panel below is served by the console's real API — nothing here is a mock-up.

▦

One mmap arena

The allocator reserves its arena once and hands out 16-byte aligned blocks from it.

⌗

First fit and split

A block larger than the request is split, so the remainder stays available.

⇄

Coalescing free list

Adjacent free blocks merge on release, which keeps fragmentation bounded.

⛭

The full C surface

malloc, free, calloc and realloc are implemented, alongside statistics for the live arena.

✓

Tested from the host

The suite exercises alignment, reuse, splitting, coalescing and realloc without a special runtime.

Architecture

How it works

Allocation walks the free list for the first block that fits, splits it when there is enough slack, and updates the live statistics. Free marks the block and merges it with its neighbours. The project is a drop-in style library with a small CLI that prints the arena after a scripted sequence of allocations and frees, which makes the coalescing visible.
