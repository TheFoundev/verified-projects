Hash it, mine it, check the chain.

A minimal proof-of-work blockchain with SHA-256 blocks, a wallet balance derived from the chain, an HTTP API, a hand-rolled WebSocket peer relay and a block explorer UI.

Open the console How it works
This is a Node.js service, not a hosted product. It is part of the Foundev portfolio: a self-contained repository with its own tests and README. The page you are reading is a project console — the numbers below are computed from the repository, and the demo runs the project's own command.
What it does

The capabilities

Every panel below is served by the console's real API — nothing here is a mock-up.

⛓

SHA-256 blocks and transactions

Transactions and blocks are hashed with the platform crypto module; no dependency supplies the chain.

⛏

Configurable difficulty

Mining searches a nonce until the block hash meets the current difficulty target.

⛨

Tamper detection

Validation recomputes every link, so editing an old block invalidates the chain.

⇄

Balances from the ledger

Wallet balances are derived by replaying the chain rather than stored in a side table.

◫

A real peer relay

A small RFC 6455 handshake and frame parser implements the WebSocket peer relay without ws.

▤

A block explorer

The served UI lists blocks, transactions and balances from the live API.

Architecture

How it works

src/blockchain.js holds the chain, the mempool and the mining loop. src/server.js exposes the HTTP API, src/node.js coordinates peers and src/ws.js implements the WebSocket handshake and framing. src/main.js is a scripted demo: it builds a chain, mines two blocks and prints the hashes, the balances and the validation result.
