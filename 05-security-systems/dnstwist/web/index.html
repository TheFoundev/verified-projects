Every way a domain can be typed wrong.

A domain permutation engine: the typosquatting candidates of a domain are generated by dropping a letter, writing one twice, using the key next door, using a homoglyph, swapping two letters and trying the other top level domains, and every candidate is looked up.

Architecture

How it works

The permutations of a domain come from six families of typos: a letter left out, a letter written twice, the key next door on the keyboard, a homoglyph, two letters swapped and the other top level domains. The lookup of a host runs in a thread that is given the time it may take, so the timeout belongs to the call and not to the whole process, and the candidates are looked up at the same time. The report of the run is a CSV with the domain, whether it resolves and the address.
