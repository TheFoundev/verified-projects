Boot, print, survive the host build.

A tiny x86 kernel with a multiboot header, a 32-bit entry stub, freestanding string and memory helpers, and VGA text-buffer utilities, tested on the host and optionally bootable.

Open the console How it works
This is a freestanding kernel, not a hosted product. It is part of the Foundev portfolio: a self-contained repository with its own tests and README. The page you are reading is a project console — the numbers below are computed from the repository, and the demo runs the project's own command.
What it does

The capabilities

Every panel below is served by the console's real API — nothing here is a mock-up.

▣

A multiboot header

GRUB can load the image through a correct multiboot header and 32-bit entry stub.

⌗

No libc

String and memory helpers are implemented in the tree because the target has no runtime.

▤

VGA text utilities

Colour, cursor and cell layout are written directly to the text buffer.

✓

Host tests

The same pure logic compiles for the host, so the checks run without a 32-bit toolchain.

◫

An optional image

make image builds a bootable artefact when a 32-bit toolchain and GRUB are present.

Architecture

How it works

src/ contains the entry stub, the freestanding helpers and the VGA routines. The host test target compiles the portable parts against a shim so the logic can be exercised on any machine. Producing a boot image is a separate, optional target because it needs a cross toolchain; this environment does not have one, which is why the test target is the honest demo here.
