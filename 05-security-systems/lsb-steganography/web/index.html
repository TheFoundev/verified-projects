Architecture

How it works

The message is encoded as a four-byte big-endian length followed by its UTF-8 bytes, and every bit is written into the lowest bit of one blue-channel pixel in row order. The decoder reads the first thirty-two bits as the length and then that many bytes back. The cover is a generated gradient with a little noise, and the PSNR of the two images says how little the payload disturbs it.

The API

Endpoints

MethodPathWhat it does
GET/api/summaryThe capacity of the image, the size of the message and the PSNR of the pair
POST/api/encodeWrite a message into a cover image and answer with the message that was read back
POST/api/decodeRead the message out of a stego image
POST/api/runRun the pipeline again and answer with the new summary
GET/console.htmlThe console of this site
