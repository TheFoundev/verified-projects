Architecture

How it works

The planner turns a container specification into a list of steps, every step a dataclass with the arguments it needs, so the plan can be read before anything runs. The namespace mask is built from the flags of the kernel, the root filesystem is generated with the layout of a small image, and the cgroup limits are written into cgroup v2 when the directory can be written. The command is then started inside the namespaces with unshare; without the rights the run stays a dry run and says why.
